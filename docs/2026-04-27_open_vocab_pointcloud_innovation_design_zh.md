# 面向 PRFNet 的开放词汇 LiDAR 分割创新方案设计

## 1）目标

设计一个明显超越“CLIP + MAE + 蒸馏”基础组合的方法：
- 训练利用 2D 基础模型语义；
- 推理阶段完全 CLIP-free，适合实时部署；
- 显式针对 LiDAR 开放词汇任务的核心难点（投影噪声、稀疏性、长尾类别）。

暂定方法名：**U-MADE**
（Uncertainty-aware Masked Alignment Distillation for Efficient Open-Vocabulary LiDAR Segmentation）

## 2）核心创新点设计

### 创新点 A：不确定性感知的跨模态掩码蒸馏

问题：
- 2D 反投影到点云的伪语义存在噪声（遮挡、标定误差、动态目标、视角歧义）。

设计：
1. 对每个点获取教师嵌入 `t_i` 与置信度 `c_i`；
2. 构建不确定性 `u_i`（多视角分歧 + 时序不一致 + 增强不一致）；
3. 蒸馏损失按置信-不确定性联合加权：
   - 高置信低不确定：强对齐；
   - 低置信高不确定：弱约束。

损失草式：
- `L_distill = sum_i w_i * (1 - cos(z_i, t_i))`
- `w_i = sigmoid(alpha * c_i - beta * u_i)`

创新价值：
- 从“直接回归特征”升级为“噪声感知蒸馏监督”，更符合 LiDAR 开放词汇场景。

### 创新点 B：原型库语义分解（语义主干 + 几何残差）

问题：
- 纯文本原型与 LiDAR 几何观测存在域差，稀有类更明显。

设计：
1. 用 prompt ensemble 构建类别文本原型；
2. 将原型分解为全局语义向量 + 几何敏感残差；
3. 学习轻量点侧适配器，预测与残差兼容的点嵌入；
4. 通过相似度完成分类。

收益：
- 提升 seen/unseen 平衡；
- 缓解图像语义到 LiDAR 几何的迁移偏差。

### 创新点 C：距离分层课程学习

问题：
- 远距离点更稀疏、更噪声，早期训练容易被错误监督拖偏。

设计：
1. 按距离把点划分为近/中/远分带（与你 RV/PB 表达天然一致）；
2. 课程策略：
   - 第一阶段强调近距离高置信样本；
   - 后续逐步提高中远距离权重；
3. 在分带上设置不同温度参数稳定相似度学习。

收益：
- 强化自动驾驶远距鲁棒性，且与 DS-AAFF 的归纳偏置一致。

### 创新点 D：显式“CLIP-free 部署目标”

问题：
- 许多方法强调精度，但对部署效率目标不够显式。

设计：
1. 在训练中加入嵌入紧致性约束；
2. 可选低秩投影头压缩最终语义嵌入；
3. 把部署指标作为主结果：
   - FPS、单帧延迟、峰值显存；
   - 对比有/无 TTA、KNN。

价值：
- 强化工程实用性与论文差异化证据。

## 3）在当前仓库中的落地方式（具体）

结合现有架构（`PRFNet` + 点级分类头），最小改造建议：
1. 在 `PointSampleAggregator` 增加语义嵌入头：输出 `e_i in R^d`（如 d=128）；
2. 增加开放词汇分类器：`logits = sim(e_i, P_text)`；
3. 新增仅训练使用的教师特征缓存加载（离线预提取）；
4. 新增损失项：
   - `L_ce_openvocab`（原型相似度分类）
   - `L_distill_uncertainty`
   - `L_curriculum_band`

推理阶段：
- 仅保留 PRFNet + 嵌入头 + 文本原型矩阵；
- 不加载 CLIP/图像编码分支。

## 4）实验方案（论文级）

### 数据与划分
1. SemanticKITTI（开放词汇 seen/unseen 协议）；
2. nuScenes-lidarseg（可选跨数据集泛化）。

### 对比基线
1. 当前 closed-set PRFNet；
2. 朴素 CLIP 蒸馏基线（无不确定性/课程学习）；
3. 可复现的最新 OV-LiDAR 方法。

### 核心指标
1. Seen mIoU
2. Unseen mIoU
3. Harmonic mIoU（seen/unseen 平衡）
4. 延迟/FPS/显存（部署）

### 消融实验
1. 仅加不确定性掩码；
2. 仅加原型分解；
3. 仅加距离课程学习；
4. 全模块联合；
5. 嵌入维度与速度-精度权衡。

## 5）为什么这条线有发表潜力

相较于常见“蒸馏后相似度分类”流程，你的最强差异应落在：
1. 面向投影噪声的不确定性感知蒸馏；
2. 面向传感器物理属性的距离分层学习；
3. 严格 CLIP-free 推理与可量化部署优势。

三点如果通过完整消融与效率评测支撑，创新性可从“中等增量”提升到“较扎实的方法贡献”。

## 6）近期可执行路线图

### 阶段 1（MVP，1-2 周）
1. 增加点级嵌入头（d=128）；
2. 构建固定文本原型矩阵；
3. 接入余弦相似度分类；
4. 跑通开放词汇评测协议。

### 阶段 2
1. 接入教师特征蒸馏（离线缓存）；
2. 加入置信度加权蒸馏损失。

### 阶段 3
1. 加入多源不确定性估计（多视角/时序/增强一致性）；
2. 加入距离分层课程学习；
3. 完成消融与效率基准。

## 7）风险与规避

1. 风险：伪标签噪声过大导致训练不稳。  
   规避：不确定性加权 + 置信阈值热启动。
2. 风险：unseen 提升但 seen 下滑。  
   规避：closed-set CE 与 open-vocab 相似度损失联合训练并调度权重。
3. 风险：效率优势不明显。  
   规避：强制 CLIP-free 推理路径并给出完整 profiling 表。
