# 一种用于户外清扫机器人的双视图激光雷达点云语义分割系统及其自监督预训练与主动学习方法

> 中国发明专利申请文件正文（说明书 "发明内容" 章节草稿）。
>
> 命名说明：为避免与现有技术中的已公开命名相撞（NOMAE / PCP-MAE 等），本文件中的子任务与监督策略均采用中文功能性描述命名；其中 DS-CAFF 为本发明所提"深度分层跨视图方位角对齐特征融合"模块的代号，其余子任务以"X 头"或"X 监督策略"形式描述其技术功能。

[0008]　一种用于户外清扫机器人的双视图激光雷达点云语义分割系统及其自监督预训练与主动学习方法，包括如下步骤：

1) 双视图特征构建与双分支主干前向：
对单帧激光雷达点云分别进行球面距离图（Range View，简称 RV）与极坐标鸟瞰图（Polar BEV，简称 PB）投影，得到两路在方位角维度共享同一宽度 W 的二维张量；将两路张量分别送入双分支编码器进行多尺度特征提取，并在每一融合尺度执行深度分层跨视图方位角对齐特征融合（Depth-Stratified Cross-view Azimuth-aligned Feature Fusion，简称 DS-CAFF），通过 RV 与 PB 在同一方位角列同一深度带内的特征均值之差所形成的跨视图差值信号参与门控权重分配；融合特征经双分支解码器后，与每个点的归一化坐标进行采样，输出逐点融合特征。

2) 双视图占据-位移联合自监督预训练：
在未标注点云上，对 RV 与 PB 分别独立采样空间掩码并以可学习掩码令牌替换被掩位置的输入特征；模型在掩码位置同时执行两个互补的重建子任务：多尺度占据重建子任务（占据头）与残差化中心位移回归子任务（中心头），其中中心头将预测目标定义为相对于当前帧可见占据格元均值中心的位移残差量，并仅在邻域不存在任何可见占据格元的远端硬例位置施加监督（稀疏邻域优先监督策略）；同时叠加双视图同方位角列余弦一致性损失，联合优化得到具有几何与语义先验的预训练权重。

3) 多准则联合主动选帧：
基于步骤 2) 所得的预训练权重，从未标注帧池中按"多检查点集成蒙特卡洛随机失活不确定性 + 最远点采样代表性筛选 + 设施位置子模函数贪心优选 + 同序列时间间隔约束"四项判据进行联合优化，选出最高价值的少量帧送入人工标注，构成低标注成本下的有监督训练集。

4) 有监督微调：
使用步骤 3) 所选标注帧对预训练主干进行有监督微调，主干部分加载预训练权重并施加较小学习率，分类头随机初始化并施加较大学习率，采用交叉熵与 Lovász-Softmax 加权损失，得到最终语义分割模型。

5) CPU/NPU 异构三级流水线推理部署：
将训练完成的网络在端侧部署时显式拆分为前处理、主干推理、后处理三个阶段，前处理与后处理运行于通用中央处理器（CPU），主干推理被导出为静态形状 ONNX 并经 RKNN 工具链转换后运行于嵌入式神经网络处理器（NPU）；CPU 与 NPU 在同一时间窗内分别处理不同帧的不同阶段，构成三级流水线。

1.5) 双分支解码：将四个尺度的融合输出由深至浅经解码器逐级上采样融合，得到与对应输入分辨率相同的解码器输出 D_rv 与 D_pb。

1.6) 逐点特征采样：对每个点 p_i，使用其在 RV 与 PB 上的归一化坐标 (u_i^{rv}, v_i^{rv}) 与 (u_i^{pb}, v_i^{pb}) 分别在 D_rv 与 D_pb 上执行双线性采样，得到逐点特征 f_i^{rv} 与 f_i^{pb}，并与点本身的几何编码拼接，构成该点最终融合特征。

进一步的，所述步骤 1.4) DS-CAFF 深度分层跨视图方位角对齐特征融合，具体为：

1.4.1) 深度分层：将 RV 分支在尺度 s 上的高度维 H_rv^{(s)} 等分为 K 个深度带（K 为预设值，典型取 K = 2），每一带覆盖一段连续的仰角区间，对应物理空间中由近及远的不同距离层；将 PB 分支在尺度 s 上的高度维 H_pb^{(s)} 同样等分为 K 个极环带，每一带覆盖一段连续的径向距离区间；两分支的分带数 K 相同，使 RV 与 PB 形成 K 对一一对应的"同深度带"。

1.4.2) 带内方位角池化：对第 k 个深度带（k = 1, 2, ..., K），将 RV 与 PB 在该带内的特征沿 H 维度做平均池化，得到 (B, C, 1, W^{(s)}) 形状的方位角列描述子 μ_rv,k 与 μ_pb,k；其中 B 为批次大小，C 为该尺度的通道数。

1.4.3) 跨视图差值信号：在每一深度带内计算同一方位角列上 RV 与 PB 的特征均值之差：

δ_k = μ_rv,k − μ_pb,k

δ_k 作为该带在该方位角列上"视图一致性"的可观测诊断量；当两视图对同一物理区域观测一致时 ‖δ_k‖ 较小，反之 ‖δ_k‖ 较大；该差值同时作为后续门控权重的输入。

1.4.4) 带内自适应门控融合：对第 k 个深度带，将 μ_rv,k、μ_pb,k 与 δ_k 在通道维度拼接后经一个 1 × 1 卷积层与 Softmax 激活，输出两路归一化门控权重 α_rv,k 与 α_pb,k（满足 α_rv,k + α_pb,k = 1）：

[α_rv,k, α_pb,k] = Softmax(Conv1×1(Concat(μ_rv,k, μ_pb,k, δ_k)))

带内融合特征定义为：

F_fuse,k = α_rv,k ⊙ μ_rv,k + α_pb,k ⊙ μ_pb,k

1.4.5) 双向带内反投影：将 F_fuse,k 沿 H 维度广播回该带在 RV 中所占的高度区间，得到 RV 分支对应的融合更新量 ΔF_rv,k^{(s)}；同样广播回该带在 PB 中所占的高度区间，得到 PB 分支对应的更新量 ΔF_pb,k^{(s)}；对各带的更新量按其在 H 维度上的位置拼接还原至全 H 维度。

1.4.6) 残差融合输出：

F_rv'^{(s)} = F_rv^{(s)} + ΔF_rv^{(s)}
F_pb'^{(s)} = F_pb^{(s)} + ΔF_pb^{(s)}

整个 DS-CAFF 过程仅由静态形状的平均池化、逐元素加法、1 × 1 卷积与广播运算构成，可被嵌入式神经网络处理器原生算子集合覆盖，便于端侧部署。

1.4.7) 与现有不分带融合方法的关键差异：
（i）RV 在 H 维度对应仰角，PB 在 H 维度对应径向距离；现有不分带方法将整段 H 一次性聚合为单个方位角列描述子，使近场密集点的特征均值主导聚合结果，远场稀疏点贡献被淹没；
（ii）本步骤通过沿 H 维度分 K 带分别聚合，保留了"近 / 中 / 远"不同距离区段的独立表征；
（iii）显式引入跨视图差值 δ_k 作为门控输入，相比仅基于 μ_rv,k 与 μ_pb,k 的拼接，提供了"两视图分歧大小"这一额外信号，使模型能够在两视图观测一致的方位角列加大单视图主导权重、在两视图观测分歧大的方位角列倾向于平衡融合。

进一步的，所述步骤 2) 双视图占据-位移联合自监督预训练，具体包括以下子步骤：

2.1) 双视图独立掩码生成：对 RV 与 PB 分别独立采样空间掩码 M_rv 与 M_pb（取值 0/1，1 表示该格元被掩），采用"随机掩码 + 矩形块掩码 + 行/列条带掩码 + 层级粗-细掩码"四类策略的加权混合方式生成；同时采用线性递增的掩码率课程，使训练前期掩码率较低（典型起点 0.60），后期掩码率较高（典型终点 0.78），令模型由易至难学习重建任务。

2.2) 输入端掩码令牌替换：对被掩位置，将其所有输入通道（含强度通道与角度位置编码通道）替换为对应视图的可学习掩码令牌 t_rv 与 t_pb：

x_rv^in = x_rv ⊙ (1 − M_rv) + t_rv · M_rv
x_pb^in = x_pb ⊙ (1 − M_pb) + t_pb · M_pb

该输入端替换阻断了模型直接读取被掩位置原始通道（如强度、距离值）作为捷径的可能性。

2.3) 编解码前向：将 x_rv^in 与 x_pb^in 送入步骤 1) 所述双分支编解码主干，得到解码器输出 D_rv ∈ R^{B × C × H_rv × W} 与 D_pb ∈ R^{B × C × H_pb × W}；后续两个重建子任务共享该主干输出。

2.4) 多尺度占据重建子任务（占据头）：以原始输入中"该格元是否存在 LiDAR 返回点"作为占据真值 y ∈ {0, 1}；对 D_rv 与 D_pb 分别经占据头 H_occ 输出 S 个尺度的占据预测 ŷ_s（典型 S = 3，对应感受野半径 k_s = 1、3、5）；占据真值通过对原始占据图按不同感受野做最大池化得到对应尺度的多尺度占据真值 y_s；采用带正样本权重的二分类交叉熵或 Focal 损失：

L_occ = − Σ_s w_s · Σ_{(h,w)∈Ω_occ_sup} [w_pos · y_s · log σ(ŷ_s) + (1 − y_s) · log(1 − σ(ŷ_s))] / |Ω_occ_sup|

其中 Ω_occ_sup = { (h,w) : M(h,w) = 1 ∧ N_vis_occ(h,w) = 1 } 为"被掩且邻域存在可见占据格元"的位置集合（informative 监督，避免完全空白邻域导致负梯度饥饿）；w_pos 可由当前批的正负样本比自适应估计，受预设上下界 [w_min, w_max] 约束。

2.5) 残差化中心位移回归子任务（中心头，详见进一步说明）：对被掩位置回归相对于"可见占据格元均值中心"的位移残差量 Δc。

2.6) 稀疏邻域优先监督策略（详见进一步说明）：将被掩格元按其邻域可见性划分为"密集邻域被掩格元"与"稀疏邻域被掩格元"两类，仅在后者上施加位移回归损失。

2.7) 双视图同方位角列余弦一致性损失：将 D_rv 与 D_pb 分别沿各自 H 维度做均值池化得到逐列描述子 D̄_rv(:, w) 与 D̄_pb(:, w)（w 为方位角列下标）；对每一方位角列定义可视权重 w_col(w)（仅在两视图该列均不全被掩时取 1，否则取 0）；一致性损失：

L_cv = Σ_w w_col(w) · (1 − cos⟨D̄_rv(:, w), D̄_pb(:, w)⟩) / Σ_w w_col(w)

该损失约束 RV 与 PB 对同一方位角扇区的特征表征在余弦相似度意义下相互一致。

2.8) 联合优化：总损失为：

L_pre = λ_occ_rv · L_occ^{rv} + λ_occ_pb · L_occ^{pb}
      + λ_pcp_rv · L_pcp^{rv} + λ_pcp_pb · L_pcp^{pb}
      + λ_cv · L_cv

其中 λ_occ_*、λ_pcp_*、λ_cv 为预设权重系数（典型 λ_occ ≈ 1.0、λ_pcp ≈ 1.5、λ_cv ≈ 0.05）；优化器采用 AdamW，学习率经线性预热与余弦退火调度。

进一步的，所述步骤 2.5) 残差化中心位移回归子任务，具体为：

2.5.1) 残差目标定义：对每一格元 (h, w)，记该格元内真实激光点的几何中心为 c_true(h, w) ∈ R³；记当前帧所有可见占据格元（即未被掩且存在 LiDAR 返回的格元）的均值中心为：

c̄_visible = Σ_{(h,w) ∈ Ω_vis} c_true(h, w) / |Ω_vis|

其中 Ω_vis = { (h, w) : M(h, w) = 0 ∧ y(h, w) = 1 }；将预测目标定义为残差量：

Δc(h, w) = c_true(h, w) − c̄_visible

2.5.2) 两阶段预测以阻断捷径学习：第一阶段从主干特征 D 经中心头第一段 H_c1 预测残差初值 Δĉ^{(1)} = H_c1(D)；对 Δĉ^{(1)} 施加停止梯度算子 sg(·)，使其反传时不通过此路径影响主干参数；按掩码位置进行替换以构造第二阶段输入上下文：

context(h, w) = M(h, w) · sg(Δĉ^{(1)}(h, w)) + (1 − M(h, w)) · Δc(h, w)

即可见位置直接使用真实残差，被掩位置使用第一阶段预测；第二阶段输入由 D 与 context 在通道维度拼接，经中心头第二段 H_c2 得到最终预测：

Δĉ^{(2)} = H_c2(Concat(D, context))

2.5.3) 损失定义：在被掩 ∩ 占据位置施加 Smooth L1 损失：

L_pcp = Σ_{(h,w) ∈ Ω_pcp_sup} w_pcp(h, w) · SmoothL1(Δĉ^{(2)}(h, w), Δc(h, w)) / Σ_{(h,w) ∈ Ω_pcp_sup} w_pcp(h, w)

其中 Ω_pcp_sup 为受稀疏邻域优先监督策略（步骤 2.6）约束的实际监督位置集合；w_pcp 为格元加权项（详见 2.5.4）。

2.5.4) 近距离与正样本加权：为兼顾近距离稠密区与正样本稀疏性，对每一格元按其物理距离与占据状态施加加权项：

w_pcp(h, w) = 1
            + 1[‖c_true(h, w)‖ ≤ R_near] · (w_near − 1)
            + 1[y(h, w) > 0.5]            · (w_pos  − 1)

其中 R_near 为预设近端距离阈值（典型 10 m），w_near 与 w_pos 为预设近端与正样本权重系数（典型 w_near ≈ 1.6、w_pos ≈ 1.2）。

2.5.5) 与回归绝对中心的现有方案的关键差异：
（i）若直接回归 c_true(h, w)，由于 c_true 的主要方差由格元自身网格位置（h, w）贡献，模型可仅通过位置编码即近似预测绝对坐标，形成"按位置抄答案"的捷径；
（ii）本步骤通过减去 c̄_visible 将"全局平移"分量从目标中扣除，使预测目标 Δc 的方差远小于 c_true 的方差，且与格元位置 (h, w) 解耦；
（iii）两阶段结构进一步隔绝第一阶段预测对主干的直接反传，使被掩位置必须依赖视觉上下文恢复局部几何偏移，习得真正具有语义判别力的特征。

进一步的，所述步骤 2.6) 稀疏邻域优先监督策略，具体为：

2.6.1) 可见邻域指示图：以预设邻域半径 r（典型 r ∈ {1, 3, 5}）对可见占据图 Ω_vis 做 (2r + 1) × (2r + 1) 最大池化，得到可见邻域指示图 N_vis_occ(h, w)：

N_vis_occ(h, w) = max_{(i,j) ∈ Window(h,w,r)} 1[(i, j) ∈ Ω_vis]

N_vis_occ(h, w) = 1 表示该格元邻域内至少存在一个可见占据格元（密集邻域），否则表示该邻域内不存在任何可见占据格元（稀疏邻域）。

2.6.2) 远端硬例位置筛选：将被掩格元按邻域可见性划分为两类：

Ω_dense_masked  = { (h, w) : M(h, w) = 1 ∧ N_vis_occ(h, w) = 1 }
Ω_sparse_masked = { (h, w) : M(h, w) = 1 ∧ N_vis_occ(h, w) = 0 }

其中 Ω_dense_masked 中的格元因邻域存在可见占据，理论上可通过简单的近邻插值即获得较好的位移估计，属于"易例"；Ω_sparse_masked 中的格元邻域无可见占据，必须依赖长程视觉上下文，属于"硬例"。

2.6.3) 损失约束：将步骤 2.5.3) 中的位移回归损失约束在硬例集合上：

Ω_pcp_sup = Ω_sparse_masked ∩ Ω_occ

L_pcp^{sparse} = Σ_{(h,w) ∈ Ω_pcp_sup} w_pcp(h, w) · SmoothL1(Δĉ^{(2)}, Δc) / Σ_{(h,w) ∈ Ω_pcp_sup} w_pcp(h, w)

2.6.4) 空集回退保护：当某帧 Ω_pcp_sup = ∅ 时（例如近距离场景或低掩码率帧），自动回退至步骤 2.5.3) 的全被掩 ∩ 占据位置监督，避免该帧训练损失为零导致的梯度饥饿。

2.6.5) 与均匀监督所有被掩位置的现有方案的关键差异：
（i）均匀监督在密集邻域被掩位置上投入大量梯度，但这些位置的几何重建可通过近邻插值平凡获得，对主干表征贡献低；
（ii）本步骤显式排除易例位置，将有效样本权重集中到稀疏邻域硬例上，等价于一种基于几何邻域可见性的难例挖掘机制；
（iii）户外清扫机器人作业场景中，稀疏邻域硬例位置在物理空间中通常对应远距离低密度区域（远端低矮障碍、路沿延伸段、稀疏行人/车辆等），恰是下游语义分割失分类风险最高的区域；该监督策略直接服务于下游目标。

进一步的，所述步骤 3) 多准则联合主动选帧，具体包括以下子步骤：

3.1) 多检查点集成蒙特卡洛随机失活不确定性估计：从步骤 2) 的预训练过程中保留 M 个不同 epoch 的检查点（典型 M ∈ {3, 4, 5}），构成检查点集合 {θ_1, θ_2, ..., θ_M}；对每个候选帧 i 与每个检查点 θ_m，启用所有 Dropout 层并执行 T 次随机前向（典型 T = 6），得到逐点类别概率分布 p_i^{m, t} ∈ R^{N_i × C}；联合分布 {p_i^{m, t} : m = 1, ..., M; t = 1, ..., T} 同时刻画"模型间分歧"与"模型内随机性"两类不确定性来源。

3.1.1) 互信息（Mutual Information）：

MI_i = H(Ē_{m,t}[p_i^{m,t}]) − Ē_{m,t}[H(p_i^{m,t})]

其中 Ē_{m,t}[·] 表示对 (m, t) 联合的平均，H(·) 为类别熵函数；MI 度量模型集成的认知性不确定性（epistemic uncertainty）。

3.1.2) 平均预测熵（Mean Predictive Entropy）：

PE_i = Ē_{m,t}[H(p_i^{m,t})]

PE 度量平均预测的总不确定性。

3.1.3) 变率（Variation Ratio）：

VR_i = 1 − max_c (1 / (M·T)) · Σ_{m,t} 1[argmax_c' p_i^{m,t}(c') = c]

VR 度量预测类别在 M × T 次前向中的不稳定程度。

3.1.4) 加权不确定性得分：

U_i = α_MI · MI_i + α_PE · PE_i + α_VR · VR_i

其中 α_MI、α_PE、α_VR 为预设权重系数。

3.2) 最远点采样代表性筛选：将每帧的特征均值或类别直方图作为帧级嵌入向量 e_i ∈ R^{d}；在嵌入空间执行最远点采样，得到大小为 B_fps 的候选子集 S_fps，使其在表征空间均匀覆盖整个帧池，避免后续选帧聚集于单一场景模式。

3.3) 设施位置子模函数贪心优选：对 S_fps 中每一帧计算不确定性得分 U_i；定义基于设施位置（facility location）的子模代表性函数：

R(S) = Σ_{j ∈ V} max_{i ∈ S} sim(e_i, e_j)

其中 V 为候选全集，sim(·, ·) 为预设相似度（典型为负 L2 距离或高斯核）；构造联合目标：

F(S) = Σ_{i ∈ S} U_i + λ · R(S)

使用贪心算法在预算 B 下逐帧选择使边际增益 F(S ∪ {i}) − F(S) 最大的帧，直至 |S| = B；λ 为不确定性与代表性的平衡系数。

3.4) 同序列时间间隔约束：对每个被选帧记录其所在序列与帧号信息；新增帧 i 时，若其与已选帧集 S 中同序列任一帧的帧号差小于预设间隔 Δ（典型 Δ = 8），则跳过该候选帧；该约束抑制了 LiDAR 由连续扫描产生的强时序冗余，避免被选帧聚集在同一时间窗内。

3.5) 输出帧列表：将最终选出的 B 帧按 "seq/stem" 格式输出至帧列表文件，供下游标注工具读取。

3.6) 与单一不确定性或单一代表性主动选帧方案的关键差异：
（i）单一不确定性方法易选出彼此高度相似的"困难"帧（冗余采集），单一代表性方法易选出对当前模型不构成挑战的"中庸"帧（学习信号弱）；本步骤通过子模函数贪心同时优化两类目标，避免两类失败模式；
（ii）多检查点集成 + MC Dropout 联合分布相比单检查点单次前向，提供了对认知性不确定性的更稳健估计，对预训练阶段尚未完全收敛的模型尤为关键；
（iii）同序列时间间隔约束契合 LiDAR 由 SLAM/里程计采集的连续帧池特性，是针对 LiDAR 时序数据的专属设计，相机图像主动学习方法中通常不需要该约束。

---

进一步的，所述步骤 4) 有监督微调，具体为：

4.1) 加载预训练权重：将步骤 2) 所得的预训练主干权重（编码器 + DS-CAFF + 解码器）加载至语义分割模型，仅替换分类头为对应类别数的随机初始化层；

4.2) 分组学习率：对加载预训练权重的主干部分施加较小学习率 lr_back，对新初始化的分类头与可选辅助头施加较大学习率 lr_head（典型 lr_head = 5 × lr_back ~ 10 × lr_back），避免微调初期分类头随机参数的梯度反传破坏预训练表征；

4.3) 损失函数：采用交叉熵损失 L_ce 与 Lovász-Softmax 损失 L_lov 的加权组合：

L_ft = β_ce · L_ce + β_lov · L_lov + γ · L_aux^{rv}

其中 L_aux^{rv} 为可选的 RV 分支辅助像素级监督损失，使用 rv_point_idx 索引获得的逐像素 GT 进行交叉熵监督；β_ce、β_lov、γ 为预设权重系数；并对类别不平衡施加倒频率类别权重。

4.4) 训练流程：在步骤 3) 所选标注帧上执行多 epoch 微调（典型 80 ~ 120 epoch），采用线性预热 + 余弦退火的学习率调度，并启用按验证集 mIoU 监控的早停策略；最终输出语义分割模型权重。

---

进一步的，所述步骤 5) CPU/NPU 异构三级流水线推理部署，具体包括以下子步骤：

5.1) 模型显式三段拆分：将训练完成的整体网络拆分为三段，按算子特性分配至 CPU 或 NPU：

- 前处理段（CPU）：原始点云读取、RV 投影、PB 投影、坐标归一化、角度位置编码生成；该段含动态索引、不规则散射（scatter）与每帧点数变化等 NPU 不友好操作；
- 主干推理段（NPU）：双分支编码器、DS-CAFF 融合、双分支解码器；该段仅包含静态形状的卷积、池化、逐元素与逐通道运算，被导出为静态形状 ONNX 并经 RKNN 工具链转换为 NPU 模型；
- 后处理段（CPU）：逐点特征双线性采样（grid sample）、逐点分类头前向、可选的语义后处理（最大类抑制、点云聚类）；该段含动态点数与不规则采样。

5.2) 三级流水线时序：CPU 与 NPU 在同一时间窗内分别处理不同帧的不同阶段。设第 t 帧的前处理输出为 X_t，主干推理输出为 Y_t，后处理输出为 Z_t；流水线在稳态时刻 T 同时执行：

T 时刻：
  CPU 线程 A：对帧 (t + 1) 执行前处理，产出 X_{t+1}
  NPU      ：对帧  t      执行主干推理，产出 Y_t
  CPU 线程 B：对帧 (t − 1) 执行后处理，产出 Z_{t−1}

T + 1 时刻：
  CPU 线程 A：对帧 (t + 2) 执行前处理
  NPU      ：对帧 (t + 1) 执行主干推理
  CPU 线程 B：对帧  t      执行后处理

5.3) 阶段间双缓冲队列：在 CPU 前处理段与 NPU 之间设置缓冲队列 Q_pre→npu，在 NPU 与 CPU 后处理段之间设置缓冲队列 Q_npu→post，长度均典型为 2；上游阶段产出数据后写入下游队列，下游阶段从队列读取；当队列满时上游阻塞、当队列空时下游等待，保证三阶段稳态运行而不发生数据竞争。

5.4) 端到端延迟与吞吐：单帧端到端延迟由三阶段串行总和退化为流水线建立阶段的总和：

L_total = L_pre + L_npu + L_post

稳态吞吐则由三阶段中最长者决定：

Throughput_steady = 1 / max(L_pre, L_npu, L_post)

在主干推理时间 L_npu 通常显著大于 CPU 两段的典型部署平台上（例如 RK3588 6 TOPS NPU 平台），稳态吞吐近似为 1 / L_npu，相比顺序执行的 1 / (L_pre + L_npu + L_post)，吞吐率近似提升至原方案的 (L_pre + L_npu + L_post) / L_npu 倍。

5.5) 失步保护：当任一阶段出现异常（如点云丢帧、NPU 推理超时、grid sample 越界）时，流水线触发降级回退路径，跳过该帧并保持后续帧时序与队列状态，避免单帧异常导致整个流水线级联阻塞。

5.6) 与现有"整网塞入 NPU"或"全 CPU 顺序执行"方案的关键差异：
（i）"整网塞入 NPU"方案在面对 RV/PB 投影与 grid sample 等不规则操作时被迫降级为 CPU 算子调用或采用近似实现，往往造成精度损失或推理失败；
（ii）"全 CPU 顺序执行"方案丧失了 NPU 的算力优势，在嵌入式平台上无法满足实时性；
（iii）本步骤通过对 LiDAR 语义分割网络的特定算子结构进行显式三段拆分，并通过双缓冲队列实现 CPU/NPU 时间维度上的并行复用，使 CPU 不规则逻辑的代价被隐藏于 NPU 推理时间窗内，最终在 6 TOPS 量级嵌入式 NPU 平台上稳定达到户外清扫机器人所需的实时帧率（≥ 10 Hz）。

本发明具有以下优点及有益效果：

1. 本发明提出 DS-CAFF 深度分层跨视图方位角对齐特征融合机制，将双视图融合按深度带逐带进行；相比现有不分带的全 H 维一次性融合方法，可避免远场稀疏点在融合中被近场密集点淹没；同时显式引入跨视图差值信号 δ_k = μ_rv,k − μ_pb,k 作为同一物理区域在两视图下观测不一致性的可观测诊断量并参与门控权重分配，在保留两路视图独立信息的同时引导模型在两视图分歧大的方位角列倾向于平衡融合、在分歧小的方位角列加大单视图主导权重，相比单一拼接 / 通道注意力 / 单层方位角对齐的现有融合方法，在远端类别（远距离低矮障碍、路沿延伸段、稀疏行人 / 车辆等）上获得显著精度提升。

2. 本发明提出残差化中心位移回归子任务，将自监督预训练中的中心回归目标定义为相对于当前帧可见占据格元均值中心的位移残差量 Δc = c_true − c̄_visible；相比直接回归绝对坐标的现有掩码自编码方法，残差化扣除了由格元自身网格位置贡献的方差分量，使预测目标与位置编码解耦，阻断了模型"按位置抄答案"的捷径学习；配合两阶段预测结构进一步隔绝第一阶段预测对主干的直接反传，使被掩位置必须从视觉上下文恢复局部几何偏移，习得具有语义判别力的特征。

3. 本发明提出稀疏邻域优先监督策略，将位移回归损失约束于邻域内不存在任何可见占据格元的稀疏邻域硬例位置；相比均匀监督所有被掩位置的现有方案，显式将易例（密集邻域被掩位置）排除在监督之外，等价于一种基于几何邻域可见性的难例挖掘机制；该策略使模型在远距离低密度区域获得更强的结构推断能力，直接对应户外清扫机器人场景中失分类风险最高的远端类别；并通过空集回退保护避免特殊帧训练损失为零。

4. 本发明提出双视图占据-位移联合自监督预训练方案，对 RV 与 PB 双视图分别独立采样空间掩码并以可学习掩码令牌替换被掩输入，同时在双分支解码器输出上执行多尺度占据重建子任务与残差化中心位移回归子任务两个互补任务，并叠加双视图同方位角列余弦一致性损失 L_cv；相比单视图或单一任务的现有预训练方案，该组合提供"占据 + 位移 + 跨视图一致性"三重自监督信号，使主干在无人工标注的条件下习得几何与语义先验，显著降低下游任务对标注数据量的依赖（在 200 ~ 300 帧标注下接近全监督性能）。

5. 本发明提出多准则联合主动选帧框架，将多检查点集成蒙特卡洛随机失活提供的不确定性、最远点采样提供的表征代表性、设施位置子模函数提供的覆盖性，以及同序列时间间隔约束这四类判据进行联合优化；相比单一不确定性、单一代表性或随机选帧的现有方案，本框架在显著压缩标注预算（原始数据集的 1% ~ 5%）的同时，平均 mIoU 较随机选帧提升约 2 ~ 4 个百分点；其中多检查点集成 + MC Dropout 联合分布对预训练尚未完全收敛的模型提供更稳健的不确定性估计，时间间隔约束规避了 LiDAR 强时序冗余特性，构成针对 LiDAR 时序数据的专属设计。

6. 本发明提出 CPU/NPU 异构三级流水线推理部署方案，将整体网络显式拆分为前处理（CPU）、主干推理（NPU）、后处理（CPU）三段，并通过双缓冲队列使三段在同一时间窗内分别处理不同帧的不同阶段；相比将整个网络强行塞入 NPU 或顺序串行执行的现有部署方案，本方案在保留 RV/PB 投影与 grid sample 等 NPU 不友好算子的工程灵活性的同时，将稳态端到端吞吐由三段时间总和退化为三段最大值，使整体处理速率近似提升至最长阶段决定的上限；最终在 RK3588 类 6 TOPS NPU 平台上稳定达到户外清扫机器人所需的实时帧率（≥ 10 Hz）。

7. 本发明所述方法对激光雷达线数与扫描模式不敏感。所述 DS-CAFF、残差化中心位移回归、稀疏邻域优先监督、多准则联合主动选帧与异构三级流水线部署五项核心结构在 16 线、32 线、64 线机械式 LiDAR 与 32 ~ 64 线非重复扫描固态 LiDAR 上均可直接迁移；仅需调整 RV 高度 H 与 PB 极环数等结构超参，无需修改算法主体，便于户外清扫机器人在不同硬件平台间复用同一软件框架。

8. 本发明所述方法在户外清扫机器人典型作业场景下，通过自监督预训练 + 多准则联合主动选帧 + 有监督微调 + 异构部署的完整闭环，将"采集 → 标注 → 训练 → 部署"全链路的人力与计算成本同时压缩，使中小规模研发团队也具备在十二个月内完成 LiDAR 语义分割感知系统全栈交付的可行性，对推动户外清扫机器人产品化落地具有积极意义。
